# Jennifer Wang - Personal Page

> 基于 [modern-resume-theme](https://github.com/sproogen/modern-resume-theme) 模板构建的个人项目主页

🌐 **GitHub Pages:** [https://jenniferw-815.github.io](https://jenniferw-815.github.io)

---

## 项目简介

本项目是个人项目主页，使用 Jekyll + GitHub Pages 搭建，展示个人简介、技能、项目作品和联系方式。

## 主要修改

- 替换模板占位内容为真实个人信息（姓名、邮箱、GitHub）
- 添加 Skills 技能区块（Front-End / Tools / Other）
- 添加导航栏，支持区块跳转
- 删除不需要的社交账号和多余区块
- 移除经验/教育区块，只保留项目展示
- 修复头像不存在的问题
- 添加规格文档（docs/prd.md, docs/design.md, docs/checklist.md）

## 页面区块

| 区块 | 说明 |
|------|------|
| Hero | 姓名 + 身份 + 社交链接 |
| About Me | 个人简介 |
| Skills | 技能树（前端、工具、其他） |
| Projects | 项目展示（个人网站） |
| Contact | 邮箱联系方式 |

## 运行方式

本项目为静态 Jekyll 站点，托管于 GitHub Pages。修改 `_config.yml` 后推送即可自动构建。
